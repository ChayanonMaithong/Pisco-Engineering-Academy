เว็บนี้จัดความรู้เป็น **3 ชั้น** ที่เชื่อมกัน:

1. **Foundations** — หลักการพื้นฐานที่ใช้ข้ามสาขา
2. **Disciplines** — หลักสูตรของแต่ละภาควิชา
3. **Industry Practice** — งานจริงในอุตสาหกรรม

ทุกบทเรียนในชั้น 3 จะระบุ **ความรู้ที่ต้องมีก่อน** พร้อมลิงก์กลับไปที่ชั้น 1–2 ถ้าอ่านแล้วติดตรงไหน ให้ย้อนไปอ่านหน้าพื้นฐานนั้นก่อน

## ส่วนประกอบของทุกบทเรียน

| ส่วน | ความหมาย |
|---|---|
| ระดับ | Beginner / Intermediate / Advanced |
| ความรู้ที่ต้องมีก่อน | ลิงก์ไปหน้าพื้นฐาน |
| วัตถุประสงค์การเรียนรู้ | อ่านจบแล้วควรทำอะไรได้ |
| เนื้อหาหลัก | หลักการ สมการ แผนภาพ |
| ตัวอย่างจากงานจริง | กรณีศึกษาหรือโจทย์ภาคสนาม |
| แบบฝึกหัด | ตรวจความเข้าใจ |
| อ่านต่อ / มาตรฐาน | เช่น IEC, API |
