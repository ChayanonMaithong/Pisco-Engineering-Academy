เว็บนี้จัดความรู้เป็น **2 ชั้น** ที่เชื่อมกัน:

1. **Foundations** — ความรู้พื้นฐาน แบ่งเป็น
   - **มัธยมปลาย (ม.4–ม.6):** คณิตศาสตร์ ฟิสิกส์ เคมี ชีววิทยา
   - **มหาวิทยาลัย:** หลักสูตรและวิชาพื้นฐานของภาควิชาไฟฟ้า โยธา เครื่องกล ปิโตรเลียม เคมี อุตสาหการ
2. **Industry Practice** — งานจริงในอุตสาหกรรม: Wind, Solar, Thermal Power, Drilling

ทุกบทเรียนในชั้น 2 จะระบุ **ความรู้ที่ต้องมีก่อน** พร้อมลิงก์กลับไปที่ชั้น 1 ถ้าอ่านแล้วติดตรงไหน ให้ย้อนไปอ่านหน้าพื้นฐานนั้นก่อน

## เรียนเป็นคอร์ส

ทุกสายงานและทุกภาควิชาเป็น **คอร์สแยกกัน** เลือกคอร์สได้จากหน้า [คอร์สทั้งหมด](/courses/) แต่ละคอร์สเรียนตามลำดับดังนี้

1. **ภาพรวมคอร์ส** บอกจำนวนบท สิ่งที่จะได้เรียนรู้ และความคืบหน้าของคุณ
2. **บทเรียนทีละบท** เมนูด้านซ้ายจะแสดงเฉพาะบทเรียนของคอร์สนั้น อ่านจบแล้วกด **"เรียนจบบทนี้ · บทถัดไป"** เพื่อบันทึกความคืบหน้า
3. **แบบทดสอบท้ายคอร์ส** เปิดให้สอบเมื่อเรียนครบทุกบท ต้องได้ **70% ขึ้นไป** สอบใหม่ได้ไม่จำกัดครั้ง
4. **ประกาศนียบัตร** เมื่อเรียนครบและสอบผ่าน ใส่ชื่อแล้วพิมพ์หรือบันทึกเป็น PDF ได้

:::note
ความคืบหน้าบันทึกไว้ในเบราว์เซอร์ที่คุณใช้เท่านั้น ถ้าเปลี่ยนเครื่อง เปลี่ยนเบราว์เซอร์ หรือล้างข้อมูลเว็บไซต์ ความคืบหน้าจะหายไป
:::

## ส่วนประกอบของทุกบทเรียน

| ส่วน | ความหมาย |
|---|---|
| ระดับ | Beginner / Intermediate / Advanced |
| ความรู้ที่ต้องมีก่อน | ลิงก์ไปหน้าพื้นฐาน |
| วัตถุประสงค์การเรียนรู้ | อ่านจบแล้วควรทำอะไรได้ |
| เนื้อหาหลัก | หลักการ สมการ แผนภาพ |
| ตัวอย่างจากงานจริง | กรณีศึกษาหรือโจทย์ภาคสนาม |
| แบบฝึกหัด | ตรวจความเข้าใจ |
| อ่านต่อ / มาตรฐาน | เช่น IEC, API |
