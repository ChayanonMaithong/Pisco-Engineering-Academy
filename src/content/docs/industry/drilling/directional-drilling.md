## ทำไมต้องเจาะเอียง
- เข้าถึงแหล่งกักเก็บใต้พื้นที่ที่ตั้งแท่นไม่ได้ เช่น ใต้ชุมชนหรือใต้ทะเล
- เจาะหลายหลุมจากแท่นเดียว (pad / platform drilling)
- เจาะแนวนอนในชั้นกักเก็บเพื่อเพิ่มพื้นที่สัมผัส
- เจาะหลุมช่วยระงับเหตุ (relief well)

## คำศัพท์สำคัญ

| คำ | ความหมาย |
|---|---|
| MD (Measured Depth) | ความยาวตามแนวหลุม |
| TVD (True Vertical Depth) | ความลึกแนวดิ่ง |
| Inclination | มุมเอียงจากแนวดิ่ง (0° = ตั้งตรง, 90° = แนวนอน) |
| Azimuth | ทิศของหลุมเทียบกับทิศเหนือ |
| KOP (Kick-off Point) | จุดที่เริ่มเบี่ยงหลุมออกจากแนวดิ่ง |
| Build Rate / DLS | อัตราการเปลี่ยนมุม (°/100 ft) |
| MWD / LWD | เครื่องมือวัดทิศทางและคุณสมบัติชั้นหินขณะเจาะ |

## เครื่องมือบังคับทิศ
- **Mud Motor (Bent Housing)** — สลับระหว่างโหมด *sliding* (หยุดหมุนก้านเจาะเพื่อเลี้ยว) กับ *rotating* (หมุนเพื่อเจาะตรง)
- **Rotary Steerable System (RSS)** — บังคับทิศได้ขณะหมุนตลอด หลุมเรียบกว่าและเจาะเร็วกว่า
