## ภาพรวมหลักสูตร (ตัวอย่างโครงสร้างทั่วไป)

| ปี | กลุ่มวิชาหลัก |
|---|---|
| 1 | Calculus, Physics, Chemistry, Engineering Drawing |
| 2 | Statics, [Fluid Mechanics](/foundations/university/mechanical/fluid-mechanics/), [Thermodynamics](/foundations/university/mechanical/thermodynamics/), Geology |
| 3 | Reservoir Engineering, **Drilling Engineering**, Well Logging, Rock Mechanics |
| 4 | Production Engineering, Well Completion, Reservoir Simulation, Project |

:::caution
โครงสร้างข้างต้นเป็นตัวอย่างทั่วไป รายวิชาจริงต่างกันไปในแต่ละมหาวิทยาลัย ควรเทียบกับ มคอ. ของหลักสูตรที่ต้องการ
:::

## ความรู้ ม.ปลาย ที่ใช้มากที่สุด
- [ฟิสิกส์](/foundations/high-school/physics/): ของแข็งและของไหล, งานและพลังงาน, คลื่น (seismic)
- [เคมี](/foundations/high-school/chemistry/): แก๊ส, เคมีอินทรีย์ (ไฮโดรคาร์บอน), กรด-เบส
- [คณิตศาสตร์](/foundations/high-school/math/): ตรีโกณมิติ, เวกเตอร์ 3 มิติ, แคลคูลัส
