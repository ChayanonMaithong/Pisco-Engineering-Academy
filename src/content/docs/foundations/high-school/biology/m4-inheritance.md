**ระดับ:** Intermediate
**ความรู้ที่ต้องมีก่อน:** [เซลล์และการแบ่งเซลล์](/foundations/high-school/biology/m4-cell/) (ไมโอซิส), ความน่าจะเป็นเบื้องต้น
**ใช้ต่อใน:** การคิดเชิงความน่าจะเป็น, การปรับปรุงพันธุ์พืชพลังงาน

## วัตถุประสงค์การเรียนรู้
- ใช้ศัพท์พันธุศาสตร์ได้ถูกต้อง
- อธิบายกฎการแยกและกฎการรวมกลุ่มอย่างอิสระของเมนเดล
- ใช้ตารางพันเนตต์หาอัตราส่วนจีโนไทป์และฟีโนไทป์
- อธิบายการถ่ายทอดแบบข่มไม่สมบูรณ์ ข่มร่วม มัลติเพิลแอลลีล และยีนบนโครโมโซม X

## ศัพท์ที่ต้องรู้

| คำ | ความหมาย |
|---|---|
| ยีน | หน่วยพันธุกรรมที่ควบคุมลักษณะ |
| แอลลีล | รูปแบบต่าง ๆ ของยีนเดียวกัน เช่น A กับ a |
| ลักษณะเด่น / ด้อย | แอลลีลเด่นแสดงออกแม้มีเพียงหนึ่งชุด แอลลีลด้อยแสดงออกเมื่อมีสองชุด |
| จีโนไทป์ / ฟีโนไทป์ | ชุดแอลลีลที่มี / ลักษณะที่ปรากฏ |
| ฮอมอไซกัส / เฮเทอโรไซกัส | แอลลีลเหมือนกัน (AA, aa) / ต่างกัน (Aa) |

## กฎของเมนเดล

1. **กฎการแยก:** แอลลีลคู่หนึ่งแยกออกจากกันไปยังเซลล์สืบพันธุ์คนละเซลล์ (เกิดในไมโอซิส)
2. **กฎการรวมกลุ่มอย่างอิสระ:** แอลลีลของยีนต่างคู่กันจัดรวมกลุ่มอย่างอิสระ (เมื่ออยู่บนโครโมโซมต่างคู่)

**ผสมลักษณะเดียว:** $Aa \times Aa$

|  | A | a |
|:-:|:-:|:-:|
| **A** | AA | Aa |
| **a** | Aa | aa |

จีโนไทป์ AA : Aa : aa $= 1 : 2 : 1$ ฟีโนไทป์ เด่น : ด้อย $= 3 : 1$

**ผสมสองลักษณะ:** $AaBb \times AaBb$ ได้ฟีโนไทป์ $9 : 3 : 3 : 1$

**การผสมทดสอบ (test cross):** ผสมกับตัวที่เป็นด้อยฮอมอไซกัส (aa) เพื่อตรวจว่าตัวที่แสดงลักษณะเด่นเป็น AA หรือ Aa ถ้าลูกมีลักษณะด้อยปรากฏ แสดงว่าเป็น Aa

## การถ่ายทอดที่ไม่เป็นไปตามกฎของเมนเดล

- **ข่มไม่สมบูรณ์:** เฮเทอโรไซกัสมีลักษณะผสม เช่น ดอกลิ้นมังกรสีแดง × ขาว ได้สีชมพู
- **ข่มร่วม:** ทั้งสองแอลลีลแสดงออกพร้อมกัน เช่น หมู่เลือด AB
- **มัลติเพิลแอลลีล:** ยีนมีมากกว่า 2 แอลลีล เช่น หมู่เลือด ABO ($I^A$, $I^B$, $i$)
- **ยีนบนโครโมโซม X:** เช่น ตาบอดสี เพศชายมี X เพียงตัวเดียว จึงแสดงลักษณะด้อยได้ง่ายกว่า

## เชื่อมกับงานวิศวกรรม

:::tip[พันธุศาสตร์คือความน่าจะเป็น]
ตารางพันเนตต์คือ**ปริภูมิตัวอย่าง**ของความน่าจะเป็นที่จะเรียนใน ม.5 ทักษะการคิดว่า "เหตุการณ์อิสระสองเหตุการณ์เกิดพร้อมกันด้วยความน่าจะเป็นเท่าใด" ($\tfrac{3}{4} \times \tfrac{3}{4} = \tfrac{9}{16}$) ใช้ตรงกับการคำนวณ**ความน่าเชื่อถือของระบบ**ที่มีอุปกรณ์หลายตัว ([วิศวกรรมอุตสาหการ](/foundations/university/industrial/))

ในงานพลังงาน นักปรับปรุงพันธุ์ใช้หลักนี้พัฒนาพันธุ์อ้อยและมันสำปะหลังที่ให้ผลผลิตสูงเพื่อผลิตเอทานอลและชีวมวล
:::

## แบบฝึกหัด
1. $Aa \times Aa$ มีโอกาสได้ลูกที่มีลักษณะด้อย (aa) เท่าใด (เฉลย: 1/4)
2. $AaBb \times AaBb$ มีโอกาสได้ลูกที่มีลักษณะเด่นทั้งสองลักษณะเท่าใด (เฉลย: 9/16)
3. พ่อหมู่เลือด A (จีโนไทป์ $I^Ai$) แม่หมู่เลือด B ($I^Bi$) ลูกมีโอกาสมีหมู่เลือด O เท่าใด (เฉลย: 1/4)
4. แม่เป็นพาหะตาบอดสี ($X^CX^c$) พ่อปกติ ($X^CY$) ลูกชายมีโอกาสตาบอดสีเท่าใด (เฉลย: 1/2)
