**ระดับ:** Intermediate
**ความรู้ที่ต้องมีก่อน:** [เคมีพื้นฐานของสิ่งมีชีวิต](/foundations/high-school/biology/m4-chemistry-of-life/)
**ใช้ต่อใน:** ระบบผลิตน้ำบริสุทธิ์แบบ reverse osmosis ใน[โรงไฟฟ้า](/industry/thermal/thermal-plant-om/), การบำบัดน้ำเสีย, ก๊าซชีวภาพ

## วัตถุประสงค์การเรียนรู้
- เปรียบเทียบเซลล์โพรแคริโอตกับยูแคริโอต และเซลล์พืชกับเซลล์สัตว์
- บอกหน้าที่ของออร์แกเนลล์สำคัญ
- อธิบายการลำเลียงสารผ่านเยื่อหุ้มเซลล์ รวมถึงออสโมซิส
- เปรียบเทียบไมโทซิสกับไมโอซิส

## ทฤษฎีเซลล์และชนิดของเซลล์
สิ่งมีชีวิตทุกชนิดประกอบด้วยเซลล์ เซลล์เป็นหน่วยพื้นฐานของสิ่งมีชีวิต และเซลล์ใหม่เกิดจากเซลล์เดิม

| | โพรแคริโอต | ยูแคริโอต |
|---|---|---|
| เยื่อหุ้มนิวเคลียส | ไม่มี | มี |
| ออร์แกเนลล์ที่มีเยื่อหุ้ม | ไม่มี | มี |
| ตัวอย่าง | แบคทีเรีย | พืช สัตว์ เห็ดรา |

## ออร์แกเนลล์สำคัญ

| ออร์แกเนลล์ | หน้าที่ |
|---|---|
| นิวเคลียส | เก็บ DNA ควบคุมการทำงานของเซลล์ |
| ไมโทคอนเดรีย | สลายสารอาหารสร้างพลังงาน (ATP) ผ่านการหายใจระดับเซลล์ |
| คลอโรพลาสต์ (พืช) | สังเคราะห์ด้วยแสง |
| ไรโบโซม | สร้างโปรตีน |
| ร่างแหเอนโดพลาซึม (ER) | สังเคราะห์และลำเลียงโปรตีนและลิพิด |
| กอลจิคอมเพล็กซ์ | ดัดแปลงและบรรจุสารเพื่อส่งออก |
| ไลโซโซม (สัตว์) | ย่อยสลายสาร |
| แวคิวโอล | สะสมน้ำและสาร (พืชมีแวคิวโอลขนาดใหญ่) |
| ผนังเซลล์ (พืช) | ทำให้เซลล์คงรูป ประกอบด้วยเซลลูโลส |

## การลำเลียงสารผ่านเยื่อหุ้มเซลล์

เยื่อหุ้มเซลล์เป็นชั้นฟอสโฟลิพิดสองชั้นที่มีโปรตีนแทรก (fluid mosaic) และยอมให้สารบางชนิดผ่านได้ (เลือกผ่าน)

| วิธี | ใช้พลังงาน | ทิศทาง |
|---|---|---|
| การแพร่ | ไม่ใช้ | จากความเข้มข้นสูงไปต่ำ |
| ออสโมซิส | ไม่ใช้ | **น้ำ**เคลื่อนจากบริเวณที่สารละลายเจือจางไปยังบริเวณที่เข้มข้นกว่า |
| การแพร่แบบฟาซิลิเทต | ไม่ใช้ | สูงไปต่ำ ผ่านโปรตีนตัวพา |
| การลำเลียงแบบใช้พลังงาน (active transport) | ใช้ ATP | ต่ำไปสูง (ทวนความเข้มข้น) |
| เอนโดไซโทซิส / เอกโซไซโทซิส | ใช้ | นำสารขนาดใหญ่เข้า/ออกโดยสร้างถุง |

## การแบ่งเซลล์

| | ไมโทซิส | ไมโอซิส |
|---|---|---|
| เกิดที่ | เซลล์ร่างกาย | เซลล์สืบพันธุ์ |
| จำนวนรอบการแบ่ง | 1 | 2 |
| เซลล์ที่ได้ | 2 เซลล์ เหมือนเซลล์เดิม | 4 เซลล์ |
| จำนวนโครโมโซม | เท่าเดิม (2n) | ลดลงครึ่งหนึ่ง (n) |
| หน้าที่ | เจริญเติบโต ซ่อมแซม | สร้างเซลล์สืบพันธุ์ เพิ่มความหลากหลายทางพันธุกรรม |

ไมโทซิสแบ่งเป็นระยะ โพรเฟส → เมทาเฟส → แอนาเฟส → เทโลเฟส

## เชื่อมกับงานวิศวกรรม

:::tip[Reverse osmosis: ออสโมซิสแบบย้อนกลับ]
โรงไฟฟ้าต้องใช้น้ำบริสุทธิ์มากเป็นน้ำป้อน boiler ระบบหนึ่งที่ใช้ผลิตคือ **reverse osmosis (RO)** โดยออกแรงดันที่สูงกว่าแรงดันออสโมติกให้น้ำในฝั่งสารละลายเข้มข้น ดันน้ำ**ย้อน**ผ่านเยื่อกรองไปฝั่งเจือจาง ส่วนเกลือและสารปนเปื้อนถูกกักไว้ หลักการเดียวกันใช้ผลิตน้ำจืดจากน้ำทะเล

ส่วน**จุลินทรีย์** (โพรแคริโอต) ทำหน้าที่ย่อยของเสียอินทรีย์ในบ่อบำบัดน้ำเสีย และผลิตก๊าซชีวภาพ (มีเทน) ที่นำไปผลิตไฟฟ้าได้
:::

## แบบฝึกหัด
1. ออร์แกเนลล์ใดสร้างพลังงาน ATP (เฉลย: ไมโทคอนเดรีย)
2. แช่เซลล์พืชในน้ำเกลือเข้มข้น น้ำจะเคลื่อนที่อย่างไร (เฉลย: น้ำออสโมซิสออกจากเซลล์ เซลล์จะเหี่ยว)
3. ไมโทซิสหนึ่งครั้งได้เซลล์กี่เซลล์ และมีจำนวนโครโมโซมอย่างไร (เฉลย: 2 เซลล์ จำนวนโครโมโซมเท่าเซลล์เดิม)
4. ระบบ reverse osmosis ต้องใช้แรงดันอย่างไรจึงผลิตน้ำบริสุทธิ์ได้ (เฉลย: แรงดันที่สูงกว่าแรงดันออสโมติก เพื่อดันน้ำย้อนจากฝั่งเข้มข้นไปฝั่งเจือจาง)
