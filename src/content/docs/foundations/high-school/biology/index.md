หลายคนคิดว่าชีววิทยาไม่เกี่ยวกับวิศวกรรม แต่ในงานจริง ชีววิทยาเข้ามาเกี่ยวข้องใน **การประเมินผลกระทบสิ่งแวดล้อม, พลังงานชีวมวล, กระบวนการชีวภาพ, การยศาสตร์ และความปลอดภัยของคนทำงาน** นอกจากนี้ยังเป็นพื้นฐานของสาขาอย่าง Biomedical Engineering และ Environmental Engineering

## หัวข้อตามชั้นปี

### ม.4: เซลล์และพันธุกรรม

ทุกหัวข้อมีบทเรียนแล้ว คลิกชื่อหัวข้อเพื่อเริ่มเรียน

| หัวข้อ | สาระสำคัญ | ความเชื่อมโยงกับงานวิศวกรรม |
|---|---|---|
| [การศึกษาชีววิทยา](/foundations/high-school/biology/m4-study-biology/) | วิธีการทางวิทยาศาสตร์, การออกแบบการทดลอง | **การออกแบบการทดลอง** และการทดสอบสมมติฐาน |
| [เคมีที่เป็นพื้นฐานของสิ่งมีชีวิต](/foundations/high-school/biology/m4-chemistry-of-life/) | น้ำ, คาร์โบไฮเดรต, ลิพิด, โปรตีน, เอนไซม์ | **เอนไซม์ในอุตสาหกรรม**, การผลิตเอทานอลและไบโอดีเซล |
| [เซลล์และการแบ่งเซลล์](/foundations/high-school/biology/m4-cell/) | โครงสร้างเซลล์, การลำเลียงผ่านเยื่อหุ้ม | เทคโนโลยีเยื่อกรอง (membrane) ในการบำบัดน้ำ |
| [การถ่ายทอดลักษณะทางพันธุกรรม](/foundations/high-school/biology/m4-inheritance/), [ยีนและโครโมโซม](/foundations/high-school/biology/m4-genes-chromosomes/) | กฎของเมนเดล, DNA | — |
| [เทคโนโลยีทางดีเอ็นเอ](/foundations/high-school/biology/m4-dna-technology/) | พันธุวิศวกรรม, PCR | **Bioprocess engineering** เช่น การผลิตยาและเอนไซม์ด้วยจุลินทรีย์ |
| [วิวัฒนาการ](/foundations/high-school/biology/m4-evolution/) | การคัดเลือกโดยธรรมชาติ | แนวคิดของ **genetic algorithm** ที่ใช้หา layout ที่เหมาะสม |

### ม.5: พืชและร่างกายมนุษย์

ทุกหัวข้อมีบทเรียนแล้ว คลิกชื่อหัวข้อเพื่อเริ่มเรียน

| หัวข้อ | สาระสำคัญ | ความเชื่อมโยงกับงานวิศวกรรม |
|---|---|---|
| [โครงสร้างและการลำเลียงในพืช](/foundations/high-school/biology/m5-plant-structure/) | เนื้อเยื่อ, ไซเล็ม/โฟลเอ็ม, การคายน้ำ | ชีวมวล, agrivoltaics, การจัดการพืชพรรณใน[โซลาร์ฟาร์ม](/industry/solar/solar-pv-om/) |
| [การสังเคราะห์ด้วยแสง](/foundations/high-school/biology/m5-photosynthesis/) | ปฏิกิริยาแสง, วัฏจักรคาลวิน, พืช C3/C4/CAM | **พลังงานชีวมวล**: แกลบ ชานอ้อย ([โรงไฟฟ้าชีวมวล](/industry/thermal/thermal-power-overview/)) |
| [การสืบพันธุ์และการเจริญเติบโตของพืช](/foundations/high-school/biology/m5-plant-reproduction/) | ดอก, การปฏิสนธิซ้อน, ฮอร์โมนพืช | ผลผลิตพืชพลังงาน, การเก็บรักษาผลผลิต |
| [ระบบย่อยอาหารและระบบหายใจ](/foundations/high-school/biology/m5-digestion-respiration/) | เอนไซม์, การแลกเปลี่ยนแก๊ส, การหายใจระดับเซลล์ | **ความปลอดภัย**: ที่อับอากาศ, CO, H₂S ในงานเจาะ |
| [ระบบหมุนเวียนเลือดและภูมิคุ้มกัน](/foundations/high-school/biology/m5-circulation-immunity/) | หัวใจ, ความดันเลือด, แอนติบอดี | การทำงานกลางแจ้งในที่ร้อน, biomedical |
| [ระบบขับถ่ายและดุลยภาพ](/foundations/high-school/biology/m5-excretion/) | หน่วยไต, ADH, การควบคุมอุณหภูมิ | เทคโนโลยีเยื่อกรอง, ความร้อนในที่ทำงาน |

### ม.6: ระบบควบคุมและระบบนิเวศ

ทุกหัวข้อมีบทเรียนแล้ว คลิกชื่อหัวข้อเพื่อเริ่มเรียน

| หัวข้อ | สาระสำคัญ | ความเชื่อมโยงกับงานวิศวกรรม |
|---|---|---|
| [ระบบประสาทและอวัยวะรับความรู้สึก](/foundations/high-school/biology/m6-nervous-system/) | การรับรู้ เสียง แสง | **การยศาสตร์** (ergonomics) และขีดจำกัดของเสียงในที่ทำงาน — วิศวกรรม[อุตสาหการ](/foundations/university/industrial/) |
| [ระบบต่อมไร้ท่อและระบบสืบพันธุ์](/foundations/high-school/biology/m6-endocrine-reproduction/) | ฮอร์โมน, การควบคุมแบบป้อนกลับ, รอบประจำเดือน | แนวคิด**ระบบควบคุมแบบป้อนกลับ** (เทียบกับระบบ pitch ของกังหันลม), อาชีวอนามัย |
| [พฤติกรรมของสัตว์](/foundations/high-school/biology/m6-animal-behavior/) | การอพยพ, การนำทาง | **ผลกระทบของกังหันลมต่อนกและค้างคาว** ([Wind Farm Development](/industry/wind/wind-farm-development/)) |
| [ความหลากหลายทางชีวภาพ](/foundations/high-school/biology/m6-biodiversity/) | การจำแนกสิ่งมีชีวิต | การสำรวจพื้นที่ก่อนก่อสร้าง, พื้นที่อนุรักษ์ |
| [ระบบนิเวศและประชากร](/foundations/high-school/biology/m6-ecology/) | ห่วงโซ่อาหาร, วัฏจักรสาร, ประชากร | **การประเมินผลกระทบสิ่งแวดล้อม (EIA)**, ผลกระทบต่อสัตว์ทะเลจาก[ฟาร์มกังหันลมนอกชายฝั่ง](/industry/wind/offshore-wind/) และงานเจาะ |

## ตัวอย่าง: จาก ม.5 สู่งานจริง

พืชสังเคราะห์ด้วยแสงเปลี่ยนพลังงานแสงอาทิตย์เป็นพลังงานเคมีด้วยประสิทธิภาพราว 1–2% เมื่อคิดทั้งฤดูปลูก ขณะที่[แผงโซลาร์](/industry/solar/solar-fundamentals/)ทำได้ราว 20–23% แต่ชีวมวลมีข้อดีคือ **เก็บพลังงานไว้ได้** และนำมาเผาผลิตไฟเมื่อต้องการ
