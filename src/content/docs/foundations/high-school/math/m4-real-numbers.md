**ความรู้ที่ต้องมีก่อน:** [เซต](/foundations/high-school/math/m4-sets/), การแยกตัวประกอบ (ม.ต้น)
**ใช้ต่อใน:** ค่าความคลาดเคลื่อนที่ยอมรับได้ (tolerance), [pressure window](/industry/drilling/drilling-fluid/), สมการทุกบทในฟิสิกส์

## วัตถุประสงค์การเรียนรู้
- จำแนกจำนวนในระบบจำนวนจริง
- ใช้ทฤษฎีบทเศษเหลือและทฤษฎีบทตัวประกอบแยกตัวประกอบพหุนาม
- แก้สมการและอสมการพหุนามดีกรีสอง
- แก้สมการและอสมการค่าสัมบูรณ์ และตีความเป็นช่วงค่าที่ยอมรับได้

## ระบบจำนวนจริง

$$
\mathbb{N} \subset \mathbb{I} \subset \mathbb{Q} \subset \mathbb{R}
$$

| ชนิด | ความหมาย | ตัวอย่าง |
|---|---|---|
| จำนวนนับ $\mathbb{N}$ | 1, 2, 3, … | 7 |
| จำนวนเต็ม $\mathbb{I}$ | รวมศูนย์และจำนวนลบ | −3, 0 |
| จำนวนตรรกยะ $\mathbb{Q}$ | เขียนเป็น $a/b$ ได้ ($b \ne 0$) | 0.25, $\tfrac{2}{3}$ |
| จำนวนอตรรกยะ | เขียนเป็นเศษส่วนไม่ได้ ทศนิยมไม่รู้จบแบบไม่ซ้ำ | $\sqrt{2}$, $\pi$ |

สมบัติที่ใช้บ่อย: การสลับที่ การเปลี่ยนกลุ่ม และการแจกแจง $a(b + c) = ab + ac$

## พหุนามและทฤษฎีบทเศษเหลือ

**ทฤษฎีบทเศษเหลือ:** เมื่อหารพหุนาม $P(x)$ ด้วย $x - c$ เศษคือ $P(c)$

**ทฤษฎีบทตัวประกอบ:** ถ้า $P(c) = 0$ แล้ว $x - c$ เป็นตัวประกอบของ $P(x)$

**ตัวอย่าง:** แยกตัวประกอบ $P(x) = x^3 - 6x^2 + 11x - 6$
1. ลองแทนค่าที่หารค่าคงที่ 6 ลงตัว: $P(1) = 1 - 6 + 11 - 6 = 0$ ดังนั้น $x - 1$ เป็นตัวประกอบ
2. หาร $P(x)$ ด้วย $x - 1$ ได้ $x^2 - 5x + 6 = (x - 2)(x - 3)$
3. ดังนั้น $P(x) = (x - 1)(x - 2)(x - 3)$ และคำตอบของ $P(x) = 0$ คือ $x = 1, 2, 3$

**สมการกำลังสอง** $ax^2 + bx + c = 0$:

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

ค่า $b^2 - 4ac$ บอกจำนวนคำตอบจริง: มากกว่า 0 มี 2 คำตอบ, เท่ากับ 0 มี 1 คำตอบ, น้อยกว่า 0 ไม่มีคำตอบจริง

## อสมการ

แก้อสมการพหุนามโดยแยกตัวประกอบ แล้วใช้**เส้นจำนวน**ดูเครื่องหมายในแต่ละช่วง

**ตัวอย่าง:** $x^2 - 5x + 6 < 0 \Rightarrow (x - 2)(x - 3) < 0$
- ช่วง $x < 2$: ผลคูณเป็นบวก
- ช่วง $2 < x < 3$: ผลคูณเป็นลบ ✓
- ช่วง $x > 3$: ผลคูณเป็นบวก

คำตอบคือ $(2, 3)$

:::caution
เมื่อคูณหรือหารอสมการด้วยจำนวน**ลบ** ต้องกลับเครื่องหมายอสมการ
:::

## ค่าสัมบูรณ์

$|x|$ คือระยะห่างจาก $x$ ถึง 0 บนเส้นจำนวน และ $|x - a|$ คือระยะห่างจาก $x$ ถึง $a$

$$
|x - a| \le b \iff a - b \le x \le a + b
$$

## เชื่อมกับงานวิศวกรรม

:::tip[Tolerance และ Pressure window]
**1. ค่าความคลาดเคลื่อนของชิ้นงาน:** เพลากำหนดขนาด $50.00 \pm 0.05$ mm เขียนเป็นอสมการได้ว่า $|d - 50| \le 0.05$ หรือ $49.95 \le d \le 50.05$ ถ้าวัดได้ 50.07 mm แสดงว่าชิ้นงานไม่ผ่าน

**2. Pressure window ในงานเจาะ:** น้ำหนักน้ำโคลนต้องสูงกว่าแรงดันในชั้นหิน แต่ต่ำกว่าแรงดันที่ทำให้หินแตก เช่น $9.6 < MW < 13.0$ ppg ซึ่งเป็นอสมการสองข้าง ([Drilling Fluid](/industry/drilling/drilling-fluid/))
:::

## แบบฝึกหัด
1. จงหาเศษจากการหาร $x^3 + 2x - 5$ ด้วย $x - 2$ (เฉลย: $P(2) = 8 + 4 - 5 = 7$)
2. จงแก้อสมการ $x^2 - 5x + 6 < 0$ (เฉลย: $2 < x < 3$)
3. จงแก้อสมการ $|x - 3| \le 2$ (เฉลย: $1 \le x \le 5$)
4. สมการ $x^2 + 2x + 5 = 0$ มีคำตอบเป็นจำนวนจริงหรือไม่ (เฉลย: ไม่มี เพราะ $b^2 - 4ac = 4 - 20 = -16 < 0$)
5. ตัวต้านทานมีค่า $100\ \Omega$ และค่าคลาดเคลื่อน ±5% จงเขียนช่วงค่าที่ยอมรับได้ด้วยค่าสัมบูรณ์ (เฉลย: $|R - 100| \le 5$ หรือ $95 \le R \le 105\ \Omega$)
